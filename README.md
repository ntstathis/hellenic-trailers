# Hellenic Trailers

Website for [hellenictrailers.gr](https://hellenictrailers.gr) — official
Lamberet representative in Greece.

Static site, published with GitHub Pages from the `main` branch. Pushing to
`main` publishes to the live site within a couple of minutes.

**Updating the site content? Read [EDITING.md](EDITING.md) first.** Most text
lives in `js/translations.js`, not in the HTML pages.

**Publishing news?** In a Claude Code chat on this repo, type `/publish-news`,
attach the photo and paste the news text — it updates the website and posts to
Facebook, Instagram and the newsletter in one go (skill:
[.claude/skills/publish-news/SKILL.md](.claude/skills/publish-news/SKILL.md)).
Channel setup and credentials are documented in [MARKETING.md](MARKETING.md),
which also carries the current to-do list for the marketing channels.

Visitors can reach the company on WhatsApp (+30 695 704 5716) from a button on
every page; the number and the pre-filled messages live in `js/translations.js`.
